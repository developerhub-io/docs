### 15 Dec

- {% badge text="New" type="success" /%} **Comments**: Comments are available for all users. [Comments](../comments.md) provide a complete workflow in DeveloperHub, from ideation to publishing and re-iteration.
- {% badge text="New" type="success" /%} **Granular HTML IDs**: Documentation and pages have HTML IDs which you can use to set specific CSS rules.

### 9 Dec

- {% badge text="New" type="success" /%} **Comments**: We are rolling out a comments system for our beta users. Let us know if you'd like to be included in early features.
- {% badge text="New" type="success" /%} **Code Block - Django**: Added Django formatting for code blocks.
- {% badge text="Improvement" /%} **IE11 - Tables**: Added better support for viewing tables in IE11 and earlier.

### 25 Nov

- {% badge text="New" type="success" /%} **Page linking in Tables**: Tables now support [page links](../writing-documentation/page-linking.md).

### 23 Nov

- {% badge text="Bug Fix" type="error" /%} **Category dropdown**: Dropdown was hiding behind content.
- {% badge text="Bug Fix" type="error" /%} **Markup in Code block**: Code blocks with "None" set as language did not render markup correctly. Now None language actually renders everything as markup (html/xml).

### 20 Nov

- {% badge text="Bug Fix" type="error" /%} **API Badge**: API Badge for API links did not render correctly in lists.

### 12 Nov

- {% badge text="New" type="success" /%} **Callout Links**: Callout links became underlined and bold.

### 10 Nov

- {% badge text="New" type="success" /%} **Import page**: [Import just one page](../importing-documentation.md#import-a-page-into-developerhubio) at a time from DeveloperHub.io Darkdown format.
- {% badge text="New" type="success" /%} **Export page**: [Export just one page](../exporting-documentation.md#exporting-a-page) to DeveloperHub.io Darkdown format.
- {% badge text="Improvement" /%} **Table export format**: Tables are no longer exported into our plugin format. Instead, they are exported as markdown tables.
- {% badge text="Bug Fix" type="error" /%} **Multiple uploads**: On uploading a file with same name, we no longer cancel the upload.

### 30 Oct

- {% badge text="New" type="success" /%} **Detailed internal link selector**: Internal link selector now shows slugs for pages as well.
- {% badge text="Improvement" /%} **Delete modals**: On deleting a project, version, documentation or reference, the title will be shown when confirming deletion.
- {% badge text="New" type="error" /%} **Tables**: On modifying table contents, you will be prompted to save changes.

### 15 Oct

- {% badge text="Bug Fix" type="error" /%} **API References**: Fixes to failing to render some API References. If no scopes exist, then the table does not show anymore.
- {% badge text="Bug Fix" type="error" /%} **Code Block**: Enforced only tokenising supported languages, setting to `None` otherwise.

### 11 Oct

- {% badge text="Bug Fix" type="error" /%} **Version Cloning**: Fixed a bug where versions couldn't be cloned due to historic invalid page slugs.

### 30 Sep

- {% badge text="Bug Fix" type="error" /%} **API References**: Indentation and required field fix.

- {% badge text="Bug Fix" type="error" /%} **Edge headings**: Headings on Microsoft Edge had extra characters.

### 25 Aug

### 12 Aug
