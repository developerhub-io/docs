- {% badge text="New" type="success" /%} **API**: A new [broken links](/v1.0/api/ref#get-version-broken-links) endpoint returns every broken or risky link in a version, with the page, the link text and a plain-English reason, so you can run link checks from your own CI.
- {% badge text="Improvement" /%} **API Playground**: The [playground](/support-center/try-it-out) response pane has a Wrap toggle for long lines, and scrolling a long response no longer scrolls the page behind it.
- {% badge text="Bug Fix" type="error" /%} **Quick Switcher**: Searching for a common word across a large version no longer freezes the editor. [Find text](/support-center/quick-switcher) now shows one result per page with a count of the rest, plus a summary of total matches.
- {% badge text="Bug Fix" type="error" /%} **Tabs**: Renaming a [tab](/support-center/tabs) no longer errors when the tabs block is deleted while the name field is still open.
