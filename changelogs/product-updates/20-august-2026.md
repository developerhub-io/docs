- {% badge text="New" type="success" /%} **Feedback**: Ask the agent about your readers. It can now read the ratings and comments they left on your pages, and **Analyse with AI** in the feedback inbox opens it with the question ready to send. See [Feedback](/support-center/feedback) and [AI Agent](/support-center/ai-agent#what-the-agent-can-read).
- {% badge text="New" type="success" /%} **AI Agent**: The AI Editor shows the model your runs use beside your credit balance, and admins can select it to change it. See [AI Agent](/support-center/ai-agent#choosing-the-model).
- {% badge text="Improvement" type="info" /%} **AI Agent**: The examples on a new conversation are selectable. Pick one to fill the message box, then send it as it is or edit it first.
- {% badge text="Bug Fix" type="error" /%} **AI Agent**: Asked to write up what shipped on a day your changelog already has a post for, the agent adds to that post instead of starting a second one. See [Changelogs](/support-center/changelogs).
- {% badge text="New" type="success" /%} **Docs Digest**: The broken links report has grown into the docs digest, one email covering broken links, searches that found nothing, reader feedback, drafts still unpublished and comments nobody has resolved. Each section opens [AI Agent](/support-center/ai-agent) with the request already written, and admins pick how often it arrives under Project Settings → **Advanced**. See [Advanced Settings](/support-center/advanced-settings#docs-digest-email).
- {% badge text="New" type="success" /%} **AI Agent**: The agent can set a page's search keywords, so the terms readers typed and found nothing for can be added to the page that should have answered them. See [Page Keywords](/support-center/using-search#page-keywords).
- {% badge text="Improvement" type="info" /%} **AI Agent**: Remembered preferences are now remembered rules, and cover what to never do as well as what to always do, such as leaving a section alone or where to look first when a topic comes up. Ask the agent to drop one and it does. See [AI Agent](/support-center/ai-agent#remembered-rules).
- {% badge text="Improvement" type="info" /%} **Emails**: Every email %product% sends has been redesigned on one shared layout, and now shows a written summary in your inbox instead of the first words of the body. Bold text, headings and links are legible in dark mode again.
- {% badge text="Improvement" type="info" /%} **Self-Updating Docs**: A **Watch the setup video** link on the settings pane walks through connecting a repository. See [Self-Updating Docs](/support-center/self-updating-docs).
