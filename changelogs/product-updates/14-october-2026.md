- {% badge text="New" type="success" /%} **Synced Blocks**: [Synced blocks](/support-center/synced-blocks#variables-in-synced-blocks) can have variables, like a product name or a version, so one block can read differently wherever it is used. Each instance sets its own values or keeps the block's defaults, in the editor or through [GitHub Sync](/support-center/github-sync).
- {% badge text="Improvement" type="info" /%} **Synced Blocks**: The [synced block](/support-center/synced-blocks) form is redesigned, with the title, ID and variables in a panel beside the contents. A new block's ID fills in from its title, and the form shows how many pages use the block.
- {% badge text="Improvement" type="info" /%} **Agent Skills**: The [Agent Skills](/support-center/write-markdoc-with-ai) for AI coding agents now cover synced block files and their variables, so an agent can write and edit the synced blocks in your repository.
