- {% badge text="New" type="success" /%} **Import from Zendesk**: Move a Zendesk Help Center into %product% in a few clicks. Paste any help center URL and [Import from Zendesk](/support-center/import-from-zendesk) previews what it will bring over before anything is created, then imports the articles into the version you choose, keeping the category and section structure, rewriting internal links and heading anchors, and showing live progress you can stop at any time.
- {% badge text="New" type="success" /%} **Changelogs in GitHub Sync**: [Changelogs](/support-center/changelogs) now sync to your repository alongside your pages, so you can write a release note in Git and review it in a pull request before it goes live. Each changelog is a folder under `changelogs/` and each post is a single file, carrying its title, date and published state in frontmatter. See [GitHub Sync](/support-center/github-sync) for the layout.
- {% badge text="New" type="success" /%} **Clone a version through the API**: [Cloning a version](/support-center/managing-versions) is no longer editor-only. One call copies every documentation, page and API reference into a new version and re-points internal links at the copies, so cutting a new version can be part of your release pipeline. The clone arrives unpublished, giving you a chance to review it before publishing.
- {% badge text="New" type="success" /%} **API References**: Long references no longer have to live on one page. Turn on [One endpoint per page](/support-center/api-reference-settings#one-endpoint-per-page) and an [API reference](/support-center/api-references) opens on an overview of its servers, authentication and tags, with readers picking a single endpoint at a time from the index. Your existing links keep working.
- {% badge text="Bug Fix" type="error" /%} **Editor**: The editor now renders a page exactly as your published site does. Headings no longer grow slightly in edit mode, external links no longer pick up a stray arrow, and [code steps](/support-center/code-steps) and [code tabs](/support-center/tabs) match the published spacing and wrapping.
- {% badge text="Bug Fix" type="error" /%} **Page Linking**: A [link](/support-center/page-linking) to a heading on the same page now scrolls to that heading instead of opening a new tab on your documentation home. Copying or middle-clicking the link gives the correct deep link too.
- {% badge text="Bug Fix" type="error" /%} **API References**: Clicking an endpoint in the sidebar of an [API reference](/support-center/api-references) now scrolls it clear of the top navigation bar, instead of leaving its title tucked behind it.
