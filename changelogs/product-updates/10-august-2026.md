- {% badge text="New" type="success" /%} **PDF Export**: Tick the documentation sections and API references you want and generate a PDF of just those, instead of the whole version every time. It all lives in a pane of its own now, at Project Settings → Import \& Export → [PDF export](/support-center/pdf-export), where each past build names the sections it was made with.
- {% badge text="New" type="success" /%} **Git Sync**: Your [synced blocks](/support-center/synced-blocks) and your reader customisation now sync to your repository too, under `_synced-blocks/` and `_theme/`. Restyle your docs or edit a reusable block in a pull request, like any other change. See [GitHub Sync](/support-center/github-sync).
- {% badge text="New" type="success" /%} **Navigation**: Navigation groups can carry an icon, picked from Font Awesome or uploaded as your own image, and a changelog can now join a group instead of sitting on its own. See the [top navigation bar](/support-center/top-navigation-bar).
- {% badge text="New" type="success" /%} **Organisation Settings**: Organisation owners get an [activity log](/support-center/organisation-settings#activity-log) spanning every project the organisation owns, searchable by user, project, action, or IP, and filterable by project and scope.
- {% badge text="Bug Fix" type="error" /%} **PDF Export**: An image the exporter cannot embed is now left out with a placeholder in its place, rather than failing the whole export.
