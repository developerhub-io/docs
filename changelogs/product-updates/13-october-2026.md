- {% badge text="Improvement" type="info" /%} **Search Analytics**: A search now counts once the reader has finished typing, so search counts, top terms and empty searches no longer include half-typed words. Past days are counted the same way. See [search analytics](/support-center/search-analytics).
- {% badge text="Improvement" type="info" /%} **Editor**: Paste [images](/support-center/images) one after another without each replacing the last. Click an image to select it, then press Backspace or Delete to remove it.
- {% badge text="Bug Fix" type="error" /%} **Editor**: Changes you make while a page is saving keep the page unsaved until you save them, and a save waits for pasted [images](/support-center/images) to finish uploading. If a pasted image cannot be uploaded, the editor tells you.
