- {% badge text="New" type="success" /%} **AI Agent**: Ask for a change and have it drafted across your whole documentation version. [AI Agent](/support-center/ai-agent) now edits many pages, API references and changelog posts in one request, shows you every line it proposes, and saves nothing until you have reviewed it. Point it at a page, a reference or a code file with `@`, accept or reject a change a section at a time, and carry on editing while it works.
- {% badge text="New" type="success" /%} **Self-Updating Docs**: Attach your code repositories and the agent can check what your documentation claims against what your code actually does. Turn on pull request checks and it reads each pull request, drafts the documentation updates it implies, and reports back on the pull request without publishing anything. See [Self-Updating Docs](/support-center/self-updating-docs).
- {% badge text="New" type="success" /%} **Search Analytics**: The reader searches that came back with nothing now have a **Fix with AI Agent** button, which opens the agent ready to work out which of those terms are missing pages. See [search analytics](/support-center/search-analytics).
- {% badge text="New" type="success" /%} **AI Features**: Admins can choose the model every agent run in a project uses. Each one is rated for cost, speed and judgement, and names the provider serving it and the region it runs in, so you can rule out a region if you need to. See [AI Features](/support-center/ai-features).
- {% badge text="Improvement" /%} **Project Settings**: Git Sync is now **Docs Sync**, with its configuration and its sync history on separate tabs, and everything AI has moved into an **AI** group of its own. See [GitHub Sync](/support-center/github-sync).
